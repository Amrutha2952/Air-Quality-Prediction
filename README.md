# Air Quality Prediction Using Machine Learning

## Project Overview
This project focuses on **predicting air quality** (AQI) using **Machine Learning** and **time-series forecasting** techniques. We use historical air pollution and weather data to build a predictive model that forecasts future air quality levels.  

The main goals of this project are:  
- Understand and preprocess time-series air quality data.  
- Build predictive models using **Prophet** for forecasting.  
- Evaluate model performance using standard metrics.  
- Visualize actual vs predicted AQI, including future predictions.

---

---

## Dataset
- **Source:** UCI Machine Learning Repository (Air Quality Dataset)  
- **Columns include:**  
  - `city`, `date`, `aqi`, `co`, `no`, `no2`, `o3`, `so2`, `pm2_5`, `pm10`, `nh3`  
- **Description:** The dataset contains daily measurements of various pollutants and air quality index (AQI) for different cities.
